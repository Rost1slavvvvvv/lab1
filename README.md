## Підхід
Фреймворк не використовується: власний CSS, mobile first (`min-width`). Рівні розміри з макета: контейнер 1240 px (77.5rem), бічні поля 25 px на мобільному, секції ~100 px.

## Шрифти
Saira (основний шрифт макета), Raleway і Inter (підвал) підключені з Google Fonts, заміна не потрібна.

## Застосовані техніки (css/style.css)
| Техніка | Рядок |
|---|---|
| Змінні теми `:root` (кольори, радіуси, відступи, розміри шрифтів) | 2 |
| Темна тема лише перевизначенням змінних | 36 |
| `clamp()` для h1, h2, lead, малого тексту, заголовка картки | 18 |
| Flexbox 1 — шапка | 100 |
| Flexbox 2 — головний екран | 140 |
| Flexbox 3 — внутрішня структура картки | 206 |
| Flexbox 4 — нижній рядок підвалу | 296 |
| Grid 1 — сітка карток (2 / 3 / 4 колонки) | 205 |
| Grid 2 — колонки підвалу (2 / 5 колонок) | 291 |
| `grid-template-areas` — блок відгуку | 250 |
| Медіазапит 768 px | 303 |
| Медіазапит 1200 px | 342 |

## Додатково
- Бургер-меню з перемикачем світлої / темної теми (`js/main.js`, тема зберігається в `localStorage`, за замовчуванням береться з системи).
- Додаткова секція «Plan Your Storage in 3 Steps» (під тему варіанта).
- Лічильник кошика на кнопках «+», фіксована шапка, підсвітка пункту меню, поява секцій при прокручуванні.
- `prefers-reduced-motion`, `:focus-visible`, `loading="lazy"`.

## Каруселі й анімації
- Пагінація товарів (16 карток, кількість сторінок залежить від ширини екрана): крапки, стрілки, анімація появи карток.
- Слайдер відгуків (3 відгуки, плавна зміна тексту й фото).
- Анімації: поява головного екрана, пульсація міток, лічильники статистики, хвиля появи секцій, смуга прокрутки, hover-ефекти. Усе вимикається при `prefers-reduced-motion`.
